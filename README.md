# RostamVPN security audit, engagement RVPN-01 (October 2026)

Penetration test reports for the RostamVPN system, prepared by Red Team Ltd (Internet Mastering & Company, Inc., DBA Red Team Ltd.). Audit powered by Claude Mythos 5.1. Each report is a public, post-remediation edition: findings fixed during the engagement carry a Fix Note naming the commit and the verification performed.
